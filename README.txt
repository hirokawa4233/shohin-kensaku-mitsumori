商品検索・見積依頼サイト

この版は、これまで作っていたサイトの見た目・検索・見積依頼画面をそのまま使い、
Excelの商品データだけを更新する版です。

商品を追加・変更する方法:
1. 「価格表.xlsm」をExcelで開く
2. Sheet2の商品を追加・変更する
3. Excelで保存して閉じる
4. 「商品データを更新.bat」をダブルクリック
5. 「SUCCESS: ○○ products updated.」と表示されれば更新完了
6. 更新後のサイトが自動で開きます

重要:
- ZIPは必ず「すべて展開」してから使用してください。
- 価格表.xlsm、index.html、商品データを更新.batは同じフォルダに置いてください。
- Pythonは不要です。
- サイトを別の場所へコピーした場合は、コピー先のindex.htmlを更新するには、
  そのコピー先フォルダで商品データを更新.batを実行してください。
